How CricketQL works

A LangGraph agent that introspects your database schema and autonomously generates, validates, and executes SQL queries.

Origin

Built three times.
Worth every iteration.

The first version was embarrassing. A giant system prompt with the entire database schema dumped into it — no real AI integration, just hoping the LLM would figure it out. It hallucinated queries, returned wrong stats, and I had no idea why.

So I rebuilt it. Deterministic feature extraction for player names and metrics. Redis caching that cut LLM calls by 70%. A proper hybrid architecture. It actually worked.

Then I wanted to learn LangGraph for real — not just read the docs, but build something real with it. So I rebuilt it a third time. Ripped out the entire architecture and replaced it with a LangGraph agent using SQLDatabaseToolkit.

What surprised me most was that through all three versions, all the debugging, all the hours — I never once wanted to give up. That's probably the closest thing to knowing you're in the right field.
